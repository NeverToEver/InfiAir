# InfiAir 发布说明

本文件按 `## v<版本>` 分节，`release.sh --publish` 只取与当前版本号匹配的那一节作为 GitHub Release 正文（旧节保留在文件里作历史，不会重复发布）。发布前为新版本在顶部加一节。

---

## v3.35

### 新增

- **练习模式**：标题屏按 **P**（或结算页轮盘「练习模式」）进入，可直选 Boss 型别、起始难度与遭遇事件，专练一处不必从头打。练习局的节奏与正局一致，但**不计进度、不写存档，死亡也不会删掉你的检查点**。
- **本局记录**：跨局保留的最好成绩——存活时长 / Boss 击杀 / 最高难度档 / 目标达成。结算页会告诉你是否刷新纪录（「新纪录！」），标题屏常驻一行「历史最好」。记录不含分数，也不给任何战力。
- **高对比弹体**（辅助页）：给敌弹加亮色描边——玩家弹是白芯、敌弹是白边，不再只靠颜色区分，色觉不便时更易判读。
- **两首新曲**：Boss 战与基地休整各有独立曲目（此前整局只有一首循环），切换带淡入淡出。

### 修复

- **Windows 上高回报率鼠标的卡顿**：极高回报率（2kHz 及以上）鼠标在锁定光标时可能让帧率崩塌，随本次引擎升级收录修复。

### 文档与工程

- 引擎升级到 **Godot 4.7.2**（4.6 维护线已止）。
- 发布包内补上 `LICENSE` / `NOTICE` 与字体许可全文（此前包内缺这三样）。
- 无头冒烟扩到 **24 趟**（新增练习直选与不落盘、本局记录两局语义），core 单测扩到 **525 条**。
- 新增引擎升级的观感等价判定工具（同机 A/B 截图比对，把「看着没变」换成可复现的量化判据）。

## v3.34

### 新增

- **左下集成仪表盘**：生命分段条、燃料量槽、冲刺/弹反充能槽、母舰弹仓格与状态指示灯整合为一套 HUD 构件——生命为视觉主导（低血转红、掉血残影），燃料液位随消耗下降并带惯性晃动、低量转红，充能槽按进度填充、满格点亮并播一次外扩脉冲，「减少闪光」下停脉冲。
- **母舰召唤机库小窗**：长按 H 召唤时抬头补实况标记（点 + 秒数），底部相位轨三节点随镜头推进点亮，机库画面加扫描线与缓移亮带。
- **天赋可升级提示**：天赋点数攒够任一节点价格时，右上芯片转金并提示「可升级 · 按 G」，同时弹一条横幅；花掉点后提示消失。
- **战斗与屏幕层视觉反馈**：击杀环、弹反环、冲刺环、直击火花、暴击星芒、Boss 阶段冲击与狂暴爆发，以及血条残影、方向受击弧、事件条与 Boss 血条淡入淡出等界面动效。
- **升级后的弱辅助瞄准**：轻微修正覆盖全部敌机（此前只对约四分之一的标记敌生效，实感「弱辅瞄时有时无」）；辅助瞄准依旧只做轻微修正，快速甩枪即退出磁吸。

### 调整

- **弹速上调**：玩家弹速由 1800 提升至 2600——纵向 1080 约 0.42s、横向 1920 约 0.74s 横穿，远距离敌机不必再「等弹飞到」，中距离点射更跟手。
- **弱辅瞄档位上调**：锥角/强度由 4/6/8° 与 0.35/0.45/0.55 调整为 6/8/10° 与 0.42/0.52/0.62。

### 移除

- **开场过场**：删除开机 6 镜头约 17s 的过场演出与「默认跳过开场过场」设置项，开机直达深空机库标题屏；开局与返航继续出击的**战机入场动画**仍在。

### 修复

- **低油量燃料槽填充消失**：低油量下填充多边形与底边自交、三角化失败整块不画（恰是燃料读数最该看清的时候）。已把波幅上限与最薄可画液层判定下沉并钳制，低油量时只画液面线，不再整块丢失。
- **关于页版本号**：由引擎版本改显游戏版本号。
- **遭遇事件若干**：编队全歼/全数拦截结算口径、精英炮塔计时单帧上限与打断路径、编队离场段击落最后一架记全歼等。

- **续局丢进度**：花双倍价「风险加点」买到的那一级，读档后会静默少一级（面板显示已加点、实际效果少一档），现已保留。
- **慢动作下鼠标瞄准失灵**：Boss 狂暴的时间减速与命中顿帧期间，鼠标的辅助瞄准（粘滞/磁吸）会整体失效——手柄不受影响，因为两者的位移来源不同。现已按真实手速换算。
- **界面淡出瞬间仍能点到按钮**：「退出确认」按「取消」后的约 0.15 秒里，再点一次「不保存退出」会真的退出游戏，现已修。
- **Boss 停在视野外**：极端配置下 Boss 进场速度为零会让整局不再出波次、不再出 Boss（画面只剩背景），现已加下限护栏。
- **死亡画面残留蓄力条**：按住返航/自毁/提前离舰时被打死，进度条会停在结算画面上，现已随终局清理。
- **编队结算口径**：拆炸弹的两条路径（击落与弹反命中）收益一致；「全数拦截」这档现在真的可达（此前屏幕外的投弹也计入分母，永远拦不满）。
- **任务刷新**：三个任务槽都被「已完成未领取」占满时，刷新会白扣刷新点数且什么都不给，现已拦下。
- **屏幕震动强度**：把震动调低或关掉，不再连带把重击泛光一起关掉（两者本是独立开关）。
- **屏幕震动下的重击反馈**、蓄力条与「减少闪光」的其余几处闪动，现在都按各自的设置各管各的。

### 文档与工程

- 玩家可见文案去工程腔，统一「敌机/本局/弹体」等术语口径；教程结业语改为出击口吻。
- 工程纪律文档精简，门禁与提交纪律口径不动。
- 一轮工程审计的收口：门禁补齐若干「声称在判、实际判不出」的假绿（对账类门禁不再被注释与条件编译骗过、门禁装配校验断言与趟次同源、构建配置声明有断言、冒烟与截图探针强制隔离用户目录、门禁与冒烟加墙钟上限），core 单测扩到 458 条、无头冒烟扩到 21 趟。
