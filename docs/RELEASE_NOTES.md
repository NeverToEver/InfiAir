# InfiAir 发布说明

本文件按 `## v<版本>` 分节，`release.sh --publish` 只取与当前版本号匹配的那一节作为 GitHub Release 正文（旧节保留在文件里作历史，不会重复发布）。发布前为新版本在顶部加一节。

---

## v3.34

### 新增

- **左下集成仪表盘**：生命分段条、燃料量槽、冲刺/弹反充能槽、母舰弹仓格与状态指示灯整合为一套 HUD 构件——生命为视觉主导（低血转红、掉血残影），燃料液位随消耗下降并带惯性晃动、低量转红，充能槽按进度填充、满格点亮并播一次外扩脉冲，「减少闪光」下停脉冲。
- **母舰召唤机库小窗**：长按 H 召唤时抬头补实况标记（点 + 秒数），底部相位轨三节点随镜头推进点亮，机库画面加扫描线与缓移亮带。
- **天赋可升级提示**：天赋点数攒够任一节点价格时，右上芯片转金并提示「可升级 · 按 G」，同时弹一条横幅；花掉点后提示消失。
- **战斗与屏幕层视觉反馈**：击杀环、弹反环、冲刺环、直击火花、暴击星芒、Boss 阶段冲击与狂暴爆发，以及血条残影、方向受击弧、事件条与 Boss 血条淡入淡出等界面动效。
- **升级后的弱辅助瞄准**：轻微修正覆盖全部敌机（此前只对约四分之一的标记敌生效，实感「弱辅瞄时有时无」）；辅助瞄准依旧只做轻微修正，快速甩枪即退出磁吸。

### 调整

- **弹速上调**：玩家弹速由 1800 提升至 2600——1080 设计高度下横穿约 0.74s，远距离敌机不必再「等弹飞到」，中距离点射更跟手。
- **弱辅瞄档位上调**：锥角/强度由 4/6/8° 与 0.35/0.45/0.55 调整为 6/8/10° 与 0.42/0.52/0.62。

### 移除

- **开场过场**：删除开机 6 镜头约 17s 的过场演出与「默认跳过开场过场」设置项，开机直达深空机库标题屏；开局与返航继续出击的**战机入场动画**仍在。

### 修复

- **低油量燃料槽填充消失**：低油量下填充多边形与底边自交、三角化失败整块不画（恰是燃料读数最该看清的时候）。已把波幅上限与最薄可画液层判定下沉并钳制，低油量时只画液面线，不再整块丢失。
- **关于页版本号**：由引擎版本改显游戏版本号。
- **遭遇事件若干**：编队全歼/全数拦截结算口径、精英炮塔计时单帧上限与打断路径、编队离场段击落最后一架记全歼等。

### 文档与工程

- 玩家可见文案去工程腔，统一「敌机/本局/弹体」等术语口径；教程结业语改为出击口吻。
- 工程纪律文档精简，门禁与提交纪律口径不动。
