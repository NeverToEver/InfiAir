## v3.35

> 本版跨度为自 v3.33 以来的全部变化，同时包含未单独发布的 v3.34。

### 新增

- **天赋缓存树**：里程碑与 Boss 击杀产出天赋点进入缓存池（后进先出、超额衰减、花掉回补），长按 **G** 打开面板加点——4 大类 27 节点，派系互斥 / 专注惩罚 / 路线契约 / 风险加点四套机制互相制衡。
- **深空机库标题屏**：开机直达新标题屏——程序化星空、远处实况战场、战机跃迁飞入悬挂展示；底部「教程 / 练习」入口按钮，新的一局 / 继续走任意键与 **C**，暂停、结算、基地、设置等菜单统一为左缘圆盘。
- **机库轮展与实况深空**：悬挂展示的战机每次进场从六型里轮换（一袋之内不重复、跨袋也不连出同型），铭牌写出机型名与它的加成，标签分「现役机型 / 机库展示」两态；背景补上远景行星、残骸带、尘埃与航道浮标，窗外战场新增曳光火网、大型舰与母舰巡航、传感扫描，出场按权重与冷却抽取——固定节拍换成了实况。
- **准星自定义**：四形状（括角 / 经典十字 / 圆环 / 净点）+ 大小 / 粗细 / 间隙 / 透明度 / 旋转 / 中心点 / 描边 / 自由取色；多档案簿与 `INF1-` 准星码跨设备复刻。准星盖住敌机即变色，进入强追踪时转一圈收拢成锁定框（不靠颜色也能读）。
- **练习模式**：标题屏按 **P** 进入，可直选 Boss 型别、起始难度与遭遇事件。节奏与正局一致，但**不计进度、不写存档，死亡也不会删掉你的检查点**。
- **初始机型（六选一）**：开局前按 **M** 选机体——标准型之外另有五型特种机体，**各带一项加成与一项代价**（游隼 移动速度 +15% / 攻击力 -10% · 重锤 攻击力 +20% / 移动速度 -10% · 连弩 攻击速度 +18% / 受到伤害 +12% · 壁垒 受到伤害 -15% / 攻击速度 -11% · 巨像 血量上限 +20% / 移动速度 -12%），各有一套专属外形与悬挂展示。选定即存、新的一局生效；「继续上次出击」仍按存档里的机型（本局不能换机）。
- **五型外观各有专属特征**：翼型与挂件都拉开了——游隼是薄刃后掠锯齿翼加翼尖外挂短舱，重锤扛着肩部双联重炮与翼下六管火箭巢、机首带撞角犁，连弩机首并列双炮管（带冷却套）配翼根弹鼓与弹链，壁垒前缘五段叠层装甲带、翼面盾形甲片与机背大盾板，巨像挂两具翼下八角外挂装甲舱、机背五段环带。机型面板与标题屏悬挂展示上一眼分得出谁是谁。
- **本局检查点存档**：回基地或「保存并退出」自动落盘，标题屏出现 **C 继续上次出击**；死亡或放弃重开即删档——检查点可以续，死了不能读。
- **本局记录**：跨局保留的最好成绩——存活时长 / Boss 击杀 / 最高难度档 / 目标达成；结算页提示是否刷新纪录，标题屏常驻一行历史最好。不含分数，也不给任何战力。
- **左下集成仪表盘**：生命分段条、燃料量槽、冲刺 / 弹反充能槽、母舰弹仓格与坞态指示灯整合为一块仪表带——生命主导视线，燃料看液位，能力槽一眼回答「能不能用」。
- **教程扩为七阶段**并补上弹反课：新增第四阶段「弧光弹反」（靶机持续开火，窗口内成功弹反两发即过关，受伤不判负）；返航开基地后还要实际打开一次增幅面板。教程全部提示取**实际绑定**的键、按**最近使用的设备**报标签（手柄报 RT / LT / A…），目标行数字直接来自游戏数值；进度按阶段记录（标题屏提示「继续教程」），死亡自动重开当前阶段，卡住可长按放弃出击键跳过。
- **手柄可达标题屏入口**：底部「教程 / 练习」改为可聚焦按钮（方向键 / 摇杆移动焦点、A 确认）；键盘 T / P 与鼠标点击照旧。
- **输入回应**：击中敌机有金属 tick 音，弹反成功有专属确认音；能力冷却中或燃料不足时按下，对应槽位播一圈向内收拢的提示弧并出声；冲刺与弹反在就绪前 0.1 秒内按下会在就绪帧自动生效。
- **机体表现**：横移侧倾、开火后坐、受击沿弹道方向微移回弹、大型击毁留下燃烧残骸；连续运动中有了活体感（加速被甩在后面、甩准星时短暂落后再追上、悬停轻浮、冲刺弹跳、尾焰油门平滑）；中弹时机身被压扁、开火时被枪口火光照亮一瞬、速度变化沿机头伸缩、重伤档冒烟且引擎喘振、机动方向有 RCS 喷口点火、机上有左红右绿的航行灯。
- **动效语言**：与音乐节拍同步的呼吸、敌弹尾部能量、舰体在擦弹 / 弹反 / 受击 / 连击时的流光、敌机损伤分级、背景随战况提速（速度线、星野滚动、行星自转）；设置页新增「动效强度」滑条（可完全关闭）。
- **全息面板**：基地控制台改为全息投影语汇（发光边缘、扫描线、开页显影带），不再是被灯照亮的钢板。
- **星野重做**：星云改为能量场质感（脊状细丝 + 暗尘带），星点分暖冷色温，亮星带衍射芒，流星补头部辉光。
- **高对比弹体**（辅助页，**默认开**）：给敌弹加亮色描边，不再只靠颜色区分；想回到只按色相区分的原外观可关掉。
- **其余**：Boss 战与基地各有独立曲目（此前整局一首循环）；天赋可升级时右上芯片转金并提示；第 5 型敌机（分裂者）与精英第 4 型（重装炮台）有独立剪影；手柄震动反馈。

### 调整

- **弹速上调**：玩家弹速 1800 → 2600（纵穿约 0.42s、横穿约 0.74s），远距离不必再「等弹飞到」。
- **弱辅助瞄准覆盖全部敌机**（此前只对约四分之一的标记敌生效），档位锥角 / 强度上调为 6/8/10° 与 0.42/0.52/0.62；快速甩枪即退出磁吸。
- **减少闪光 / 屏幕震动强度 / 命中顿帧强度 / 动效强度四项互不连坐**；0% 一律明示「已关闭」。
- **续航收口**：吸血改为击杀回复 5% **基础**生命（原 10% 最大生命——与「额外生命」叠满时单杀回 40，会几乎抹掉死亡威胁）；母舰召回每级冷却缩减 50% → 25%（原满级 15s 一跳的免费满补，比一波交战还短）。

### 移除

- **登录与局外成长**：账户 / 登录欢迎页、科技树与科技点整体移除——开机即玩，成长只在本局内（天赋缓存）。
- **排行榜与局内计分显示**：分数不再显示也不作记录，改为隐藏的进度引擎（敌机解锁 / Boss 节奏 / 里程碑→天赋点）。
- **开场过场**：删除开机约 17s 的过场与跳过设置项，开机直达标题屏（开局与返航的战机入场动画仍在）。
- **移动端与触屏**：本作改为 PC 桌面专用（Windows / Linux / macOS），虚拟摇杆 / 按钮层与触屏输入路径全部移除；输入面为键鼠与手柄两路。

### 修复

- **教程不再把人丢回起点**：阵亡后重开**当前**阶段（此前只显示「任务失败」，要自己退出再从第一阶段重来）。
- **教程目标行在切换设备时被打回上一条指令**：现在切换设备只换键位标签，不换行。
- **弹反盾偶尔「时机对了却没弹」**：敌弹擦盾缘进入时判定落在盾半径外的半帧里，此后不再有第二次机会；现在有效窗口内逐帧补判。
- **Windows 上高回报率鼠标的卡顿**：极高回报率（2kHz 及以上）鼠标在锁定光标时可能让帧率崩塌，随本次引擎升级收录修复。
- **结算页的「练习模式」点了没反应**（面板被压在结算页之下）；**练习局死亡的结算页误报「新纪录」**；**练习开局少了入场演出**（现与正局同路径，含约 2.1s 无敌窗口）。
- **记录档损坏或版本不符后整场不再记录**：现按「没有记录」处理，照常写入。
- **开了「减少闪光」仍有三处在闪**：低血晕影回退路径、迷雾全屏变色、星场亮星闪烁现已受开关约束（星场改均值常亮）。
- **低油量燃料槽填充消失**（多边形自交导致整块不画）；**续局丢风险加点**（双倍价买到的那一级读档后静默少一级）；**慢动作下鼠标辅助瞄准失灵**；**界面淡出瞬间仍能点到按钮**；**Boss 停在视野外**（极端配置下整局不再出波次，已加下限护栏）；**死亡画面残留蓄力条**。
- **标题屏悬挂展示的尾焰从机身中段冒出来**：尾焰与喷口辉光的坐标写死在展示机里且取错了位置（X 外挂到机身之外、Y 落在机身中段），现改为按机体骨架的双发喷口锚点取位——尾焰从机尾两个喷口喷出，焰长压在铭牌上缘之内。
- **编队结算口径**：拆炸弹的击落与弹反命中收益一致，「全数拦截」档现在真的可达；**任务刷新**不再白扣点数；**屏幕震动强度**不再连带关掉重击泛光；关于页改显游戏版本号。

### 文档与工程

- 引擎升级到 **Godot 4.7.2**（4.6 维护线已止）；发布包内补上 `LICENSE` / `NOTICE` 与字体许可全文。
- **启动期着色器预热**：开机交接标题屏前把场景里的着色器材质各画一帧，把编译成本从「按下开始那一帧」前移到开机黑场。
- **验证门禁收缩为五步主干**（C# 构建零警告 / core 单测 / 离线工具链自测 / 资源导入 / 开机冒烟），core 单测 **692 条**，全跑由分钟级收到十秒级。
- **数值管理器升级为数值工作台**：`scripts/tools/balance_editor.py` 补上键级中文说明 / 单位 / 取值范围、搜索、改动清单与备份回滚，新增「平衡分析」页（难度曲线 / 战斗节奏 / 经济与进度，每条公式标 C# 出处）与按感受选的快速预设；设置页留了游戏内入口（仅源码运行可用），改完数值回到标题屏即生效。
- **发布前置判据**：`./release.sh --publish` 先断言工作树干净、版本号与工程一致、origin 同源、tag 未占用、五步门禁全绿，之后才推送与建 Release。
- 性能：软点贴图改为共享缓存；爆炸对象池保留上限此前形同虚设（判据恒真），现在真正生效。
- 无障碍判据落地：全屏尺度脉冲源的频率与「减少闪光」处置单源在 core `FlashBudget`，单测断言频率 < 3Hz（XAG 118 / WCAG 2.3.1）与减闪下振幅为零（两半互补）。
- **文档最小化**：活跃文档收敛为「README（双语）/ AGENTS / DESIGN_BASELINE / ROADMAP / REFERENCES / 本文件」，两份只读存档删除、原文留在 git 历史（依据见 [REFERENCES](REFERENCES.md) §4.13）。
