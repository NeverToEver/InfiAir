# InfiAir 发布说明

本文件按 `## v<版本>` 分节，`release.sh --publish` 只取与当前版本号匹配的那一节作为 GitHub Release 正文（已发布版本的历史节保留在文件里，不会重复发布）。发布前在顶部为新版本加一节。

---

## v3.35

> 本版跨度为自 v3.33 以来的全部变化，同时包含未单独发布的 v3.34。

### 新增

- **天赋缓存树**：里程碑与 Boss 击杀产出天赋点进入缓存池（后进先出、超额衰减、花掉会回补），长按 **G** 打开面板自主加点——4 大类 27 节点，派系互斥、专注惩罚、路线契约、风险加点四套机制互相制衡，构筑没有免费午餐。
- **深空机库标题屏**：开机直达新标题屏——程序化星空、远处实况战场（敌机编队 / 爆炸 / Boss 剪影）、你的战机跃迁飞入悬挂展示，左缘圆盘菜单进入新的一局 / 继续 / 教程 / 练习；全站菜单（暂停、结算、基地、设置）统一为左缘圆盘导航。
- **准星自定义**：准星从写死的样式变成你自己的档案——四种形状（括角 / 经典十字 / 圆环 / 净点）、大小 / 粗细 / 间隙 / 透明度 / 旋转 / 中心点 / 描边开关 / 自由取色；档案簿可切换、复制、重命名、删除（至少留一档）；**准星码**（`INF1-…`）复制粘贴即可跨设备复刻样式。设置页新增「准星」页，带实时预览。
- **准星交战反馈**：准星盖住敌机时变红粉（此刻开火能命中），进入强追踪目标时变金热色并转一圈收拢成锁定框；锁定另有旋转与收拢两路线索，不靠颜色也能读。
- **练习模式**：标题屏按 **P**（或结算页轮盘「练习模式」）进入，可直选 Boss 型别、起始难度与遭遇事件。节奏与正局一致，但**不计进度、不写存档，死亡也不会删掉你的检查点**。
- **本局检查点存档**：回基地或「保存并退出」自动落盘，标题屏出现 **C 继续上次出击**；死亡或放弃重开即删档——检查点可以续，死了不能读。
- **本局记录**：跨局保留的最好成绩——存活时长 / Boss 击杀 / 最高难度档 / 目标达成；结算页提示是否刷新纪录，标题屏常驻一行历史最好。记录不含分数，也不给任何战力。
- **左下集成仪表盘**：生命分段条、燃料量槽、冲刺 / 弹反充能槽、母舰弹仓格与坞态指示灯整合为一块仪表带——生命主导视线，燃料看液位，能力槽一眼回答「能不能用」。
- **教程扩为七阶段**，并补上弹反课：新增第四阶段「弧光弹反」——弹反是本作唯一的防御手段，此前教程全程不提。段内靶机持续朝你开火，在弹反窗口内成功弹反两发即过关（受伤不判负）；返航开基地后还要实际打开一次增幅面板。
- **教程按你的键位与设备说话**：所有「按某个键」都取实际绑定（改键后教程跟着变），键标签按最近使用的设备取档（键鼠报键名、手柄报 RT / LT / A…）；目标行里的数字直接来自游戏数值，改平衡就跟着改；进度按阶段记录（标题屏提示「继续教程」）；死亡自动重开当前阶段；卡住时长按放弃出击键可跳过本阶段。
- **手柄可达标题屏入口**：底部「教程 / 练习」改为可聚焦按钮——方向键 / 摇杆移动焦点、A 确认；键盘 T / P 与鼠标点击照旧。
- **输入回应**：击中敌机有金属 tick 音，弹反成功有专属确认音；能力冷却中或燃料不足时按下，对应槽位播一圈向内收拢的提示弧并出声；冲刺与弹反在就绪前 0.1 秒内按下会在就绪帧自动生效（早了一点也不丢）。
- **机体表现**：横移侧倾、开火后坐、受击沿弹道方向微移回弹、大型击毁留下燃烧残骸；机体在连续运动中有了活体感（加速被甩在后面、甩准星时短暂落后再追上、悬停轻浮、冲刺弹跳、尾焰油门平滑）；中弹时机身被压扁、开火时被枪口火光照亮一瞬、速度变化沿机头伸缩、重伤档冒烟且引擎喘振、机动机方向有 RCS 喷口点火、机上有左红右绿的航行灯。
- **动效语言**：屏幕与音乐节拍同步的呼吸、敌弹尾部能量、舰体在擦弹 / 弹反 / 受击 / 连击时的流光、敌机损伤分级、背景随战况提速（速度线、星野滚动、行星自转）；设置页新增「动效强度」滑条（可完全关闭）。
- **全息面板**：基地控制台与母舰召唤小窗改为全息投影语汇（发光边缘、扫描线、开页显影带），不再是被灯照亮的钢板。
- **星野重做**：星云改为能量场质感（脊状细丝 + 暗尘带），星点分暖冷色温，亮星带衍射芒；流星补头部辉光。
- **高对比弹体**（辅助页，**默认开**）：给敌弹加亮色描边，不再只靠颜色区分，色觉不便时更易判读；想回到只按色相区分的原外观可关掉。
- **两首新曲**：Boss 战与基地休整各有独立曲目（此前整局只有一首循环），切换带淡入淡出。
- **手柄震动**：开火 / 受击 / 击杀 / Boss 演出等事件带震动反馈（走引擎力反馈，手柄支持时生效）。
- **天赋可升级提示**：点数攒够任一节点价格时，右上芯片转金并提示「可升级 · 按 G」，同时弹一条横幅。
- **两型敌机各有自己的样子**：第 5 型（分裂者）与精英第 4 型（重装炮台）此前借用其他型的贴图，现在有独立剪影。

### 调整

- **弹速上调**：玩家弹速 1800 → 2600——纵穿约 0.42s、横穿约 0.74s，远距离不必再「等弹飞到」。
- **弱辅助瞄准覆盖全部敌机**（此前只对约四分之一的标记敌生效），档位锥角 / 强度上调为 6/8/10° 与 0.42/0.52/0.62；快速甩枪即退出磁吸。
- **减少闪光 / 屏幕震动强度 / 命中顿帧强度 / 动效强度四项互不连坐**，各管各的；0% 一律在设置里明示「已关闭」。

### 移除

- **登录与局外成长**：账户 / 登录欢迎页、科技树与科技点整体移除——开机即玩，成长只在本局内（天赋缓存）。
- **排行榜与局内计分显示**：分数不再显示也不作记录，改为隐藏的进度引擎（敌机解锁 / Boss 节奏 / 里程碑→天赋点）。
- **开场过场**：删除开机约 17s 的过场与「默认跳过开场过场」设置项，开机直达深空机库标题屏（开局与返航的战机入场动画仍在）。
- **移动端与触屏**：本作改为 PC 桌面专用（Windows / Linux / macOS），虚拟摇杆 / 按钮层与触屏输入路径全部移除；输入面为键鼠与手柄两路。

### 修复

- **教程不再把人丢回起点**：阵亡后重开**当前**阶段（此前只显示「任务失败」，要自己按 Esc 退出再从第一阶段重来）。
- **教程目标行在切换设备时被打回上一条指令**：母舰对接说明会被换成「长按 <键> 蓄力召唤母舰」——现在切换设备只换键位标签，不换行。
- **弹反盾偶尔「时机对了却没弹」**：敌弹擦着盾缘进入时判定落在盾半径外的半帧里，此后不再有第二次机会，看起来就是弹从盾里穿过。现在有效窗口内逐帧补判。
- **Windows 上高回报率鼠标的卡顿**：极高回报率（2kHz 及以上）鼠标在锁定光标时可能让帧率崩塌，随本次引擎升级收录修复。
- **结算页的「练习模式」点了没反应**（面板被压在结算页之下）。
- **练习局死亡的结算页误报「新纪录」**；**练习开局少了入场演出**（现与正局同路径，含约 2.1s 无敌窗口）。
- **记录档损坏或版本不符后整场不再记录**：现按「没有记录」处理，照常写入。
- **开了「减少闪光」仍有三处在闪**：低血晕影回退路径、迷雾全屏变色、星场亮星闪烁现已受开关约束（星场改均值常亮，平均亮度不变）。
- **低油量燃料槽填充消失**（多边形自交导致整块不画——恰是燃料读数最该看清的时候）。
- **续局丢进度**：花双倍价「风险加点」买到的那一级读档后会静默少一级，现已保留。
- **慢动作下鼠标辅助瞄准失灵**（Boss 狂暴子弹时间与顿帧期间磁吸整体失效，手柄不受影响）。
- **界面淡出瞬间仍能点到按钮**：退出确认按「取消」后约 0.15 秒内再点「不保存退出」会真的退出，现已修。
- **Boss 停在视野外**：极端配置下 Boss 进场速度为零会让整局不再出波次、不再出 Boss，现已加下限护栏。
- **死亡画面残留蓄力条**；**编队结算口径**（拆炸弹的击落与弹反命中收益一致，「全数拦截」档现在真的可达）；**任务刷新**不再白扣点数；**屏幕震动强度**不再连带关掉重击泛光；关于页改显游戏版本号。

### 文档与工程

- 引擎升级到 **Godot 4.7.2**（4.6 维护线已止）。
- 发布包内补上 `LICENSE` / `NOTICE` 与字体许可全文（此前包内缺这三样）。
- **启动期着色器预热**：开机交接标题屏前把场景里的着色器材质各画一帧（Compatibility 后端没有 ubershader，着色器首次被绘制时才编译），把编译成本从「按下开始那一帧」前移到开机黑场。
- **验证门禁收缩为四步主干**（C# 构建零警告 / core 单测 / 资源导入 / 开机冒烟），core 单测 **666 条**；全跑由分钟级收到十秒级。
- **发布前置判据**：`./release.sh --publish` 会先断言工作树干净、版本号与工程一致、origin 与发布通道同源、tag 未占用、四步门禁全绿，之后才推送与建 Release。
- 性能：软点贴图由「每次用到都重建」改为共享缓存；爆炸对象池的保留上限此前形同虚设（判据恒真），现在真正生效。
- 无障碍判据落地：全屏尺度脉冲源的频率与「减少闪光」处置单源在 core `FlashBudget`，单测断言「频率 < 3Hz」（XAG 118 / WCAG 2.3.1）与「减闪下振幅为零」两半互补。
- **文档最小化**：活跃文档收敛为「README（双语）/ AGENTS / DESIGN_BASELINE / ROADMAP / REFERENCES / 本文件」，两份只读存档（平衡审查、决策史归档）删除，原文留在 git 历史（行业依据见 [REFERENCES](REFERENCES.md) §4.13）。
