# 门禁命中台账

> **非纪律存档，只读用途**：每道门禁一行，记「它最近一次拦到真缺陷是什么」（日期 + 一句话 + 证据提交）。
> 用途：提议删或降级某道门禁之前先查这里——它是「按证据退役」的唯一依据面，`AGENTS.md` §6 的准入门槛要求新门禁写明退役条件，而**退役条件要靠本表来判**。
> **没有命中记录不等于可删**：本表多数行现在写「未记录」，那是**没建台账**而不是门禁没用；毁档防护、恶意档防护、写读对称这类低频高价值面一律按风险保留（Google 的 effective false positive 口径是「告警后无人采取行动才算无效」，不是「没报过算无效」）。
> **维护**：门禁拦下真缺陷并修掉之后，就地更新该行（日期 + 一句话 + 提交）；破坏验证不算命中（那是证明它能红，不是它抓到过）。
> **行集由 `check_gate_wiring.sh` 断言**与 `scripts/ci/gates.py` 的步骤登记集一一对应：新增门禁必须带一行，缺行或指向不存在的门禁都判红。

## 与本表的联动

- 提议删/降级门禁时：先查本表的「最近命中」，再看该门禁脚本里写明的**退役条件**（`AGENTS.md` §6 准入门槛要求）。
- 本表与 `gates.py` 的登记集由 `check_gate_wiring.sh` 双向绑定；本表不重复登记各门禁的判据口径（那在各自脚本注释里）。
