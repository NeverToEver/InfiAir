# InfiAir 路线图（未来方向与初步计划）

> 2026-07-24 立项。本文是项目方向的单一事实源；阶段调整时更新本文并在 AGENTS.md「文档同步要求」登记。

## 现状快照（2026-07-24）

- **移植对齐收官**：Python/Pygame 原作的全部核心机制已重制并对齐（逐项对照见 `docs/PORTING_PARITY.md` 差距清单，仅剩「本地排行榜页」一个可选项）。
- **质量基线**：17 个无头测试场景 586 项断言全绿；长时 autoplay 探针 + 性能基准可用。
- **协作就绪**：隐私隔离审计通过（无密钥/个人信息泄露、git 历史已清洗）、UI 字体替换为 OFL 开源的 NotoSansSC、文档基线（README / AGENTS / PORTING_PARITY / EXIT_FLOW）已与代码逐条核对。

## 方向转变

| 维度 | 过去（~3.13） | 未来 |
| --- | --- | --- |
| 目标 | 逐项对齐原作，消除移植差距 | 以重制版自身路线独立演进；原作仅作数值/设计参考，不再逐行对齐 |
| 开发模式 | 单人开发 | 协作开发（仓库已具备协作者条件） |
| 发布 | 明确暂缓打包 | 以可发布为目标补齐工程化（导出预设、CI、版本流程），发布本身仍待用户决策 |
| 内容 | 机制补全 | 体验深化与新内容（在原作框架之外扩展需先在本文登记） |

## 阶段计划

### Phase 0 — 技术债收尾（近期，无新玩法）

- 审计 P2 待办清理（`docs/2026-07-22-audit-fix-plan.md`）：死代码删除（`main.gd` 未用引用、`hud.gd` 恒假分支、零 connect 信号等）、母舰 `_start_release()` 幂等守卫、`profile_corrupt` 损坏档案提示消费。
- 敌机生成路径统一：普通波次目前直接实例化、Boss-3 小怪走 `enemy_pool`，两条路径并存；评估统一到对象池（含 A/B 性能对照，`USE_POOL` 开关已留）。
- 验收：全部既有测试 0 FAIL；改动条目在审计文档标注完成。

### Phase 1 — 协作与发布工程化

- `CONTRIBUTING.md`：从 AGENTS.md 摘出贡献者流程（分支/提交约定、测试准入、文档同步要求）。
- CI（GitHub Actions）：无头跑 `--import`、`--quit-after 300`、核心断言场景，PR 准入。
- 可审查的导出流程：`export_presets.cfg` 模板入库（先脱敏审查，当前被 gitignore 排除）、导出命令写入 AGENTS.md，覆盖桌面三平台；Android 视需求（返回键已适配）。
- 版本策略：迭代号语义化（对齐 git tag），发布说明随 tag 生成。

### Phase 2 — 内容演进

- 本地排行榜页（纯本地最高分榜，不依赖账号系统；移植差距清单 #22 的唯一遗留）。
- 新内容候选（逐项立项后再进迭代）：新 Buff 品类（池 16 种之外）、新敌机/精英类型、第 4 种 Boss、移动端触屏操控方案。
- 体验深化：~~狂暴期表现强化~~（2026-07-28 已由 Boss 行为重设计落地：阶段化模式表 + 三型专属狂暴 + telegraph + 难度分档，见 `docs/BOSS_REDESIGN.md`）、母舰玩法扩展（当前为补给+火力平台）。

### Phase 3 — 暂缓项的重启条件（均需用户明确决策）
