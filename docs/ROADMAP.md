## Current State (2026-09-17)

- **决策线重置（2026-09-17，人类授权全权决策）**：工程收口阶段结束，方向转为**发布与可衡量性**。依据：工程侧已无实质空缺（16 步门禁 / 22 趟冒烟 / 399 条 core 单测 / 素材可复现 / 文档与代码逐条对得上），对外侧为零——GitHub 仓库 7 个 release 合计资产下载 11 次、无商店页、无演示、无预告片。内容是**有限解冻**：只做「记录 / 练习 / 表现」三类元层项，玩法系统扩展（新 Boss / 遭遇 / 天赋 / 机体）仍冻结。阶段与顺序见「工作计划」，取舍理由与反转链见 Decisions 同日条目。
- 纯街机流口径不变（2026-09-08 用户指令）：账户/登录、排行榜、局外成长（研究所/科技点）全量移除；开机流程 = `scenes/main.tscn` 开机直达 `scenes/title.tscn` 深空机库标题屏（形态详见 DESIGN_BASELINE §1.12）→ 开局（2026-09-13 移除开场过场）。**分数仍是隐藏进度引擎**（敌机解锁/Boss 节奏/事件门控/里程碑→天赋点），局内计分显示与连击计数维持已裁状态（2026-09-13 口径）——P1 的本局记录只到「局末结果」层，不复活计分显示。无尽必死曲线（D1）为既定设计。
- 本局存档回归（2026-09-10，反转 09-08「无对局存档」）：单存档位检查点模型——保存退出/回基地落盘，死亡或放弃重开删档，标题屏可读档续局。口径见 DESIGN_BASELINE §2.5。
- 内容演进：4 Boss 轮换、母舰火力平台、天赋缓存系统（2026-09-07，替代旧里程碑三选一与 line→双 buff 路线，低血保底随之退役）；2026-09-17 起**有限解冻**（仅「记录 / 练习 / 表现」三类，边界见 DESIGN_BASELINE §1.16）。
- 平台收束（2026-09-11，方向变化）：**PC 桌面专用、移动端不做**（产品范围决定），输入面 = 键鼠 + 手柄两路；触屏虚拟控件与 Android 返回路径全量退役（口径见 DESIGN_BASELINE §1.14）。预编译包 = Windows / Linux 两路，macOS 维持源码运行（预编译包列为发布后按证据推进）。
- 引擎面：**已升级到 Godot 4.7.2**（2026-09-17；此前停在 4.6.2，维护线止于 4.6.3）。动机＝高回报率（≥2kHz）鼠标在 Windows 捕获模式下的帧率崩塌在 4.7.2 / 4.8.dev3 才修，而本作是鼠标瞄准优先 + 有「鼠标锁定」设置。全量门禁在 4.7.2 上 16/16 绿；观感与实机手感（含 2kHz+ 鼠标）仍待窗口化过目（人工项）。

- 质量形态：CI 单 job fast-gate 与本地门禁一致（口径见 AGENTS.md）；回归验证 = core 单测 + 无头固定步长冒烟，GPU 表现 / 手感 / 长时稳定性另做窗口化人工过目。

## 已知债务与开放发现

> 唯一登记处，只保留未关闭项；修复后直接删除（变更史在 git log）；新发现追加在末尾。

**现存三条（均为低）。** 2026-09-17 收尾批次曾清空本节：三条「未自动化」的判据都做成了能失败的门禁（零引用成员登记 / balance 反向死键 / 素材生成可复现性），三条业务收口（读档补给超载槽上限单源、任务刷新受阻原因常显、数值编辑器双向键集校验），两处布局缺陷（蓄力条槽位互压、Boss 名牌底衬压血条）修复并各加运行期护栏，编队投放裁剪口径定稿——逐条证据见 Decisions 对应条目。

- **[低] 素材门禁的「产物同步」在非产出环境上是包络级判定**：`check_assets_reproducible.sh` 已改成机器无关的两段判据（结构 + 抗锯齿包络 + 同机两次重跑一致），CI 与本地都能稳定复现；**残留**的是它无法在非产出环境上判「逐字节同步」——那里只声明「产物同步未在本机判定」并打印残差（实测 CI 上残差全是「像素逐位一致、仅编码字节不同」一类，像素层面本可复现；macOS 上才有字形边缘的栅格化像素差）。为什么不现在做：要逐字节跨机一致，得让生成器不依赖 Pillow 图像库的卷积/栅格化实现（自绘重采样、或产物改为矢量/程序化绘制），属美术管线改造，收益与代价需人定；**触发时机**＝下次改素材生成器或整理发布流程时。**收口条件**＝生成器输出与后端无关（或明确定义「产出环境」并在该环境上跑一次严格模式）。
- **[低] 练习面板只有无头判据、没有视觉判据**：练习模式的冒烟趟断的是「面板开页 + 三行直选 + 交出的设置等于面板显示 + 直选走生产链」，而截图探针只覆盖 HUD 与五张设置页——新面板的排版/可读性没有视觉判据（同批的死亡结算页已纳入 `--shot-probe`，练习面板没有）。为什么不现在做：它需要把练习面板排进固定帧序列（面板在选择态与确认态各一张），属探针扩面，收益低于当前队列里的项。**收口条件**＝`--shot-probe` 增补练习面板截图（含选择态），并由截图探针自检「非空白且与既有各页互异」。**触发时机**＝下次动练习面板或探针序列时。
- **[低] 资源导入门禁在「脚本集合变化后的首次导入」会吃到一条 EditorSettings 噪声 ERROR**：新增/删除 `.cs` 后的第一次 `godot --headless --import` 会打 `ERROR: EditorSettings not instantiated yet when getting setting "export/android/android_sdk_path".`（与项目无关的编辑器设置读取时序），第二次导入即干净；门禁按「日志零 ERROR」判红，故此刻为假红。为什么现在不消：根因在引擎侧读取时序，白名单化会把真正的导入错误一并放过，需先判明该噪声的出现条件；**触发时机**＝下次动导入门禁或增删脚本时。**收口条件**＝判据能区分该噪声与真实导入错误（或确认其为特定引擎版本行为并写进白名单并附破坏验证）。

## Decisions

- **2026-09-17 自动游玩探针以收窄范围回归**：把「一个不会累的玩家」按生产输入面重接回探针宿主（`--autoplay-probe`），判「能开局但玩不起来」这一类——整局零击杀、存活却连续 60 模拟秒无得分无击杀、跑局中的引擎错误；CI 只跑 180 模拟秒（≈8s 墙钟），长局（=900）登记为发布前人工项。反转链：2026-08-29「测试与 CI 大幅削减」退役了当年的 autoplay 探针（连同 51 个断言场景，理由是 CI 成本）；本次回归的差异是范围——单趟短局进 CI + 长局人工，不恢复多监视器套件，也不重开断言场景。

> 摘要登记（决策 + 为什么 + 反转链），一行一条；细节见 git 历史与 DESIGN_BASELINE。

- **2026-08-05 统一实体/事件管理器**：EntityManager/GameEventManager 收敛注册样板、生命周期信号与随机事件分组并发。
- **2026-08-08 全量迁移 C#**（反转 2026-08-07 渐进混编）：终态零 GDScript、单一语言维护；csharp/core 与 csharp/godot 分层由此确立。
- **2026-08-09 局外成长（科技树）**：死亡结算唯一入口防刷点；效果 = 开局预置 buff 层数，复用 buff 计算链零新属性管道；不破坏 D1 必死曲线。
- **2026-08-11 得分/奖励审核**：连击计分温和版 + 低血防御保底；明确不做炸弹/掉落物/技能树重构（复杂度预算外）。
- **2026-08-29 测试与 CI 大幅削减**：51 断言场景 + autoplay 探针退役，CI 收敛单 fast-gate；行为回归 = xUnit + 两场景 + 人工窗口化验证。
- **2026-09-07 工程纪律裁剪**（「惯例恶心且冗杂」）：13 份行为规格退役归档、审计档案/SOP 废止、活文档收敛 5 份、BALANCE_MAP 去行号、注释禁审计轮次编号。依据：双源漂移曾消耗专门纠偏轮次；审计档案 1900+ 行持续膨胀。
- **2026-09-07 天赋缓存系统重构**（反转 2026-08-11「不做技能树重构」）：19 个既有 buff 节点组织成树，里程碑/Boss 点数入缓存池（LIFO 衰减），G 蓄力自主加点；四机制 = 派系互斥/专注惩罚/路线契约/风险加点。
