## 已知债务与开放发现

> 唯一登记处，只保留未关闭项；修复后直接删除（变更史在 git log）；新发现追加在末尾。

**现存三条（均为低）。**

- **[低] 素材门禁的「产物同步」在非产出环境上是包络级判定**：`check_assets_reproducible.sh` 的判据是「结构 + 抗锯齿包络 + 同机两次重跑一致」，CI 与本地都能稳定复现；**残留**的是它无法在非产出环境上判「逐字节同步」——那里只声明「产物同步未在本机判定」并打印残差（实测 CI 上残差全是「像素逐位一致、仅编码字节不同」一类；macOS 上才有字形边缘的栅格化像素差）。本批按该条的**触发时机**改过一次素材生成器（新增两型贴图）并复核：判据本身未变（新增产物逐字节一致、既有产物仍走 ENCODING/WITHIN 归因），缺口依旧是跨机逐字节一致**做不到**——那要生成器不依赖 Pillow 的卷积/栅格化实现（自绘重采样、或产物改矢量），属美术管线改造，收益与代价需人定。**收口条件**＝生成器输出与后端无关（或明确定义「产出环境」并在该环境上跑严格模式）；**触发时机**＝下次整理美术管线或发布流程时。
- **[低] 启动巨帧的主项是场景装载、不是着色器编译**：同机分段实测（M2 / Metal / 1280×720，`--startup-time`）：`Main._Ready` 装载约 570ms（**无头也是这个量级**，即 CPU 侧：建 FX、加载贴图与场景），首帧含绘制约 110ms（无头 15ms，差值里才是着色器编译与管线初始化）。着色器预热只能前移后一项，装载那一半要压只能**分帧构建** `Main._Ready` 里的表现层（HUD / 星空 / 后处理各摊到几帧），代价是开机链路与入场时序要重新对齐。**收口条件**＝装载耗时降到首帧绘制的量级（同机分段读数对比）；**触发时机**＝玩家反馈启动慢，或下次要动开机链路与表现层构建顺序时。
- **[低] 一次性闪光（就绪脉冲、血条掉段闪、Boss 阶段闪）的减闪门控没有判据**：它们无频率可言（不进 core `FlashBudget`），门控是各自实现里的一句布尔分支，改坏只表现为「开减闪后仍闪一下」——`--settings-probe` 的采样面覆盖不到（它已覆盖轮盘开机、危险横幅、低燃料脉冲三处周期型）。**收口条件**＝任一趟探针按正反两半采样一次（先断无减闪时确实闪、再断减闪下恒定）；**触发时机**＝下次动这些特效或探针采样面时。
