## How to change values

- `data/balance.json` is the single source of runtime values; prefer editing it in the browser with `python3 scripts/tools/balance_editor.py` (change highlighting, type validation, auto backup).
- Script-side `GameState.cfg("key path", fallback)` only covers missing/corrupted json keys; per AGENTS.md, keep json and fallback values in sync when adding or adjusting values.
- Cache values on hot `_process` paths once in `_ready()`/`_load_balance()`; do not query them per frame.
